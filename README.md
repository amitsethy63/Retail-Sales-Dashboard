# 📊 Retail Sales Dashboard – Power BI

## 📌 Project Overview
This project analyzes retail sales data and presents key business insights through an interactive Power BI dashboard.

## 🎯 Objectives
- Analyze total sales revenue.
- Compare sales performance across products.
- Identify regional sales trends.
- Display important business KPIs.
- Support data-driven decision-making.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## 📈 Dashboard Features
- Total Sales KPI
- Total Quantity Sold KPI
- Distinct Product Count KPI
- Sales Revenue by Product
- Sales by Region
- Interactive visualizations
